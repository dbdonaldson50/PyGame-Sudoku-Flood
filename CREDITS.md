## How to Download Audio Files

### For Freesound.org files:
1. Visit the URL provided above
2. Click "Download" button on the sound page
3. Save the file with the exact filename listed above
4. Place it in the `assets/sounds/` or `assets/music/` directory

### For OpenGameArt.org files:
1. Visit the URL provided above
2. Click the download link for the file
3. Convert to appropriate format if needed (OGG for music, WAV for effects)
4. Save with the exact filename listed above
5. Place it in the appropriate assets directory

---

## File Structure

Place downloaded files in these directories:

```
assets/
├── music/
│   └── background.ogg
└── sounds/
    ├── correct.wav
    ├── wrong.wav
    ├── hint.wav
    ├── undo.wav
    ├── button.wav
    ├── win.wav
    └── combo.wav
```
