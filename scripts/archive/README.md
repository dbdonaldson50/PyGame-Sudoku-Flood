# Scripts Archive

This directory contains historical diagnostic and verification scripts that were used during development to debug specific UI issues. These scripts are no longer needed for regular development but are preserved for reference.

## Archived Scripts

### Text and UI Measurement Tools
- **measure_text_overlaps.py** - Used to debug text overlap issues (fixed)
- **measure_positions.py** - Used to debug UI element positioning (fixed)
- **measure_button_texts.py** - Used to debug button width issues (fixed)

### UI Verification Tools
- **test_no_overlaps.py** - One-time overlap verification (completed)
- **test_board_boundaries.py** - One-time boundary check (completed)
- **test_cell_fit.py** - One-time cell size verification (completed)
- **verify_fixes.py** - Verification of UI fixes (completed)
- **verify_modal_visual.py** - Modal visual check (completed)
- **verify_ui_fixes.py** - UI fixes verification (completed)

### Debugging Tools
- **test_debug_large_grids.py** - Debugging large grid rendering (fixed)
- **test_font_consistency.py** - Font width verification (fixed)
- **inspect_layout.py** - Layout debugging (fixed)
- **diagnostic_remaining_modal.py** - Modal logic debugging (fixed)

## Status

All issues verified by these scripts have been resolved and documented. The solutions are now part of the main codebase and covered by the test suite.

**Reason:** Issues resolved, scripts no longer needed
